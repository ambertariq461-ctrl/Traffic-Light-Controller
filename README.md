# Traffic Light Controller with Pedestrian Crossing

Arduino Uno project simulated in Wokwi, written in C++.

## What it does
- Controls car and pedestrian lights with a four-state machine
- A pedestrian button shortens the car green phase
- Non-blocking timing with millis()
- Prints each state change to the Serial Monitor

## Pins
Car red 13, yellow 12, green 11 | Pedestrian red 10, green 9 | Button 2

## Files
- `sketch.ino`: the program
- `diagram.json`: the circuit wiring for Wokwi
